agry

  
A tiny macOS menu bar app that keeps your Mac awake while coding agents work, then lets it sleep.

  
Agents report what they're doing with OSC 7501 status records. agry reads them for every session in Rex and holds off sleep for as long as each state warrants.

  

    
working
stay awake

    
blocked
30 min, waiting on you

    
done
5 min

    
idle
sleep as usual

  

  

    
      
      Download for macOS
    
    macOS 15 or later
